# איזה כיף! מישהו תרם לפרויקט open source שלי! תוסף דפדפן שבשימוש כבר של יותר מ10 אלף אנשים!

איזה כיף! מישהו תרם לפרויקט open source שלי! תוסף דפדפן שבשימוש כבר של יותר מ10 אלף אנשים!

בניתי את real-browser-mcp, פרויקט open source שמאפשר לסוכני AI לעבוד בדפדפן האמיתי שלכם, עם החשבונות שכבר מחוברים אליו.

ואתמול נכנס אליו קוד של מישהו אחר.

תורם בשם webLiang הציע שיפורים לניהול קבוצות טאבים ולחיבור של התוסף למנגנון ה-debugger של Chrome.

במהלך ה-review עלו כמה בעיות: שתי פעולות במקביל יכלו ליצור שתי קבוצות לאותו טאב. חיבור ל-debugger היה עלול להיחשב מוצלח גם כשהוא שייך לכלי אחר. היו גם מצבים שבהם שני טאבים יכלו להתחבר, כשהקוד עוקב רק אחרי אחד מהם.

התגובה שלו הייתה לחזור עם פתרון.

הוא פיצל את העבודה לשני PRs, תיקן את המקרים שעלו ב-review, הוסיף בדיקות שמכסות אותם וסגר בעצמו את ה-PR הישן לטובת החדשים. הראשון כבר מוזג אתמול.

לפרסם קוד זה רגע אחד. לקבל בחזרה תרומה שעברה את כל הדרך הזאת זה רגע אחר לגמרי.

תודה ל-webLiang. כיף לראות את הפרויקט נבנה גם בידיים של אחרים.
