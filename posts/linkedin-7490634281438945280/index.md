הפקודה שאצלי הכי הרבה בשימוש וחוסכת לי ים זמן - /back-to-master-delete-branch
משהו מאוד סזיפי שאנחנו בפיתוח עושים כל הזמן, ופקודה אחת שחררה אותי מהעול - למחוק את הברנץ המקומי שמוזג למאסטר, ולחזור למאסטר מעודכן

ממליץ בחום

התוכן של ה-Cursor command למי שמעוניין להגדיר גם אצלו:

````
# back-to-master-delete-branch
I dont need this branch locally anymore
Pull latest of master
Switch to master
and delete this branch (locally only!) once we're on master branch
```
