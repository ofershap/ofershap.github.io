# A real-world flight simulator built with Opus and Codex

February 12, 2026 · 1 min read

Originally posted on LinkedIn , February 12, 2026.

In 2025, Levelsio posted a flight simulator he had built through vibe coding. Now the CEO of Grw AI has built a simulator that lets you fly over real locations around the world. Israel is not on the list, in case you were wondering.

@alistairmcleay described the process:

I used Opus 4.6 for the architecture / planning and GPT-5.3 in Codex for the actual implementation With Opus passing context to Codex

You can try the flight simulator yourself . I had a blast flying it, literally.
