# A Telegram bot that turns messages into calendar events

February 15, 2026 · 1 min read

Originally posted on LinkedIn , February 15, 2026.

I built a Telegram bot that adds all the events thrown at me every day to my calendar, including school events, birthdays, tasks, appointments, and treatments. I simply send it a message with the details, and it creates the calendar event. My life has become much easier.

Inspired by a post from the brilliant Lorin Totah Hayat, I built my own version, with Cursor, of course. To save everyone some tokens and back-and-forth, I made it open source so anyone can set it up easily.

I think this is a must-have tool for every parent now, and it is pretty simple to get running.
