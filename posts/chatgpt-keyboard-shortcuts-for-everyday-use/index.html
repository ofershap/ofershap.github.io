ChatGPT keyboard shortcuts for everyday use

May 10, 2025 · 1 min read

Originally posted on LinkedIn, May 10, 2025.

If you use ChatGPT every day, these keyboard shortcuts can make it faster:

  • Shift + Esc: Jump to the message box
  • Ctrl + Shift + C: Copy the last response
  • Ctrl + Shift + ;: Copy the last code block
  • Ctrl + Shift + O: Open a new chat
  • Ctrl + Shift + I: Open custom instructions settings
  • Ctrl + Shift + S: Show or hide the sidebar
  • Ctrl + /: Show the full list of keyboard shortcuts

On a Mac, replace Ctrl with Cmd (⌘) in the shortcuts above.

One more shortcut that many people miss: use Shift + Enter to start a new line without sending the message.
