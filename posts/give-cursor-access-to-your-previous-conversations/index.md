# Give Cursor access to your previous conversations

January 29, 2026 · 1 min read

Originally posted on LinkedIn , January 29, 2026.

I found a Cursor hack that gives it access to your previous conversations. Add this User Rule:

Leave [YOUR-WORKSPACE-PATH] exactly as written. It will work in every project you open.

You can then ask Cursor questions about past conversations, have it analyze them and extract insights, find conversations that disappeared, or return to topics you started but never finished.

Cursor stores these conversations for 30 days, so this only gives it access to the last 30 days.
