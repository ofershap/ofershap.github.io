# Goose runs an open-source coding agent locally

February 4, 2026 · 1 min read

Originally posted on LinkedIn , February 4, 2026.

Block, formerly known as Square, released Goose , an open-source agent that runs AI on your local machine. Unlike Anthropic's Claude Code, which requires an expensive subscription, Goose gives you all its features for free and can work without an internet connection.

Goose is not tied to a specific model. You can connect it to Claude, OpenAI's GPT-5, or open models through tools such as Ollama. It supports the work developers need, from writing code to interacting with external APIs.

The latest version, 1.20.1, was released in January 2026 and already has more than 26,100 stars on GitHub. That shows how many developers are looking for flexible tools that protect their privacy.
