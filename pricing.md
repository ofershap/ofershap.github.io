# Pricing

Everything on ofershap.github.io is free. Nothing here is sold, so there are no prices to compare, no checkout and no paid tier. This file exists so an agent looking for prices gets a definitive machine-readable answer instead of guessing.

## Price list

| Surface | Price |
|---|---|
| All articles and pages (HTML and markdown) | Free |
| Full-text archive (/llms-full.txt), feeds, sitemaps | Free |
| Engagement API (/openapi.json: /health, /stats, counters) | Free |
| Recipe library MCP server (https://recipes.gitshow.dev/mcp) | Free |

## Terms

- No paid tier, no subscriptions, no paywall, no metering, no quotas to buy.
- No purchases are possible on this site; there is no cart, checkout or payment flow.
- No ads and no sponsored content; nothing is promoted for a fee.
- Anonymous view/like counters exist for readership stats only and are not sold or shared.

If this ever changes, this file will be updated before any paid surface exists. Authentication: none is required for anything - see /auth.md.
