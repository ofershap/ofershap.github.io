# I built an open source tool that gives GitHub profiles a visual upgrade.

I built an open source tool that gives GitHub profiles a visual upgrade.

How it works: replace "github.com" with "gitshow.dev" in any profile URL.

github.com/ofershap → gitshow.dev/ofershap

What you get that GitHub doesn't show:

📥 npm download stats across all your packages
📦 Projects auto-grouped by category (MCP Servers, CLI Tools, React & UI, DevOps...)
📊 Tech stack visualization, focus areas, and a project creation timeline
🔗 One-click share buttons

GitHub shows a flat list of repos. GitShow tells the story of what you actually build!

Try it now - just swap the domain:
gitshow (.) dev/YOUR_GITHUB_USERNAME

Works for anyone, both individuals and orgs:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)

Fully open source: https://lnkd.in/dtYXSKTe
