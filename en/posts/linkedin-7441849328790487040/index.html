I run 5+ Cursor cloud agents in parallel. Keeping track of them was chaos.
So I built a Control Tower! 🗼

One terminal command and you can get a view of all your agents on one screen: Running, done, errored - all visible at a glance.

You can also launch new agents, send follow-ups, stop runaways. All from the keyboard.

How to get it? Just write:
```
npx agents-control-tower
```
That's it. 10 seconds to set up.

Repo & Details here: https://lnkd.in/dEZPFuDJ
