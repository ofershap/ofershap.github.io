Now in Hebrew too: I built an open-source tool that visually upgrades GitHub profiles 😎

How it works: replace github.com with gitshow.dev in any profile address, for example:
github.com/ofershap → gitshow.dev/ofershap

And you get features that GitHub doesn't have:

📥 npm download statistics for all of your packages
📦 Projects automatically grouped by category (MCP Servers, CLI tools, React and UI, DevOps and more)
📊 Visualization of the stack, focus areas, and a timeline of project creation
🔗 One-click share buttons

GitHub shows a flat list of repositories. GitShow tells the story of what you actually build.

You're welcome to try it - just swap in your own domain:
gitshow (.) dev / YOUR_USERNAME

It works for everyone, both personal profiles and organizations:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)

And it's all open source:
