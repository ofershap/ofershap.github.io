I use Cursor's agent mode all day. At some point, I realized I kept checking the terminal to see if the agent was still working or done. so I built this: a pixel art office that sits in the bottom panel and reacts to what the agent is doing.

Character types at the desk when the agent writes code. Walks around and pets the cat when idle. Celebrates when a build passes. Every object is clickable - lamp, window, arcade cabinet, bookshelf, water cooler.

It works by watching Cursor's JSONL transcript files. Read-only, no API keys, no patching Cursor.

The whole thing is 27KB.

Every sprite is drawn pixel by pixel from TypeScript, no image files at all.
I wanted to see how far I could push canvas-based pixel art with zero assets.

Would love to hear what objects or features people want in their office.
There's a plugin API if anyone wants to add their own furniture or new bg.

It's available as a Cursor extension:
https://lnkd.in/dCpfVge8

And also as an open-source project:
