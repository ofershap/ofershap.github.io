# This developer burned $1500 in one day without knowing it at all! And worse - without anyone else knowing about it

This developer burned $1500 in one day without knowing it at all! And worse - without anyone else knowing about it
At the company we use Cursor on a shared account (an Enterprise account), so we have one budget and one blanket that every developer pulls toward himself. Keeping to the budget is a challenge everyone faces today.

In addition, there is model inflation and it's hard to know and tell which model is better and which model is expensive or cheap. So in his innocence the developer chose a model that supposedly sounds cheaper (it contains the word Fast) - but in practice this model is 10 times more expensive than the others.

So we paid some tuition here, and I decided to develop a tool that monitors and reports in real time on anomalies and irregularities in usage - and reports them to our Slack

Beyond monitoring, it also lets you see the organization's adoption level, identify "empty seats" that are being paid for as a subscription for nothing, developer usage optimization, management and comparison between teams, the real costs of the models in use, and a lot of really interesting data

Thanks to this tool we could know which models we want to block, which models cost more and which less, and how it's better to use Cursor and share that with the development department

I built it as open source so that anyone suffering from this problem can deploy it on their side 😎
If you're interested, this is the repo: https://lnkd.in/djZRK5ZP
