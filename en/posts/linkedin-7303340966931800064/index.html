I just recreated Alley Cat – the legendary game from the 80s! 🫨🐈‍⬛
This week I came across a post where someone took an MS-DOS EXE file, asked Claude to analyze it, and got it to rewrite the whole thing in Python.

I had to try it myself,
so I pulled out the game "Alley Cat", one of my favorites from childhood.
I downloaded the EXE file from a game archive site, and opened the Cursor development tool with a "simple" prompt:
👉 "Rebuild this for me, with Pygame!"

And then like magic:
💡 Cursor planned the whole process by itself.
💡 Extracted the content, analyzed, installed libraries, and recreated the code - all without me touching a single line of code!
💡 A quarter of an hour later I could already play a remade version that closely resembles the original.

We're in an era where AI doesn't only help us write code - it understands, interprets, and recreates it from scratch. Every day I'm surprised anew at how far you can get with these capabilities.
