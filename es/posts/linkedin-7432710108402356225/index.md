Ahora también en hebreo: construí una herramienta de código abierto que mejora visualmente los perfiles de GitHub 😎

Cómo funciona: reemplaza github.com por gitshow.dev en cualquier dirección de perfil, por ejemplo:
github.com/ofershap → gitshow.dev/ofershap

Y obtienes funciones que GitHub no tiene:

📥 Estadísticas de descargas de npm de todos tus paquetes
📦 Proyectos agrupados automáticamente por categoría (MCP Servers, herramientas CLI, React y UI, DevOps y más)
📊 Visualización del stack, de las áreas de enfoque y una línea de tiempo de creación de proyectos
🔗 Botones para compartir con un clic

GitHub muestra una lista plana de repositorios. GitShow cuenta la historia de lo que realmente construyes.

Te invito a probarlo, solo cambia por tu propio dominio:
gitshow (.) dev / YOUR_USERNAME

Funciona para todos, tanto perfiles personales como organizaciones:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)
