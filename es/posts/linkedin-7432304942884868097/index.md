Construí una herramienta de código abierto que da a los perfiles de GitHub una mejora visual.

Cómo funciona: reemplaza "github.com" por "gitshow.dev" en cualquier URL de perfil.

github.com/ofershap → gitshow.dev/ofershap

Lo que obtienes y GitHub no muestra:

📥 Estadísticas de descargas de npm de todos tus paquetes
📦 Proyectos agrupados automáticamente por categoría (MCP Servers, herramientas CLI, React y UI, DevOps...)
📊 Visualización del tech stack, de las áreas de enfoque y una línea de tiempo de creación de proyectos
🔗 Botones para compartir con un clic

GitHub muestra una lista plana de repos. ¡GitShow cuenta la historia de lo que realmente construyes!

Pruébalo ahora, solo cambia el dominio:
gitshow (.) dev/YOUR_GITHUB_USERNAME

Funciona para cualquiera, tanto particulares como organizaciones:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)

Totalmente de código abierto: https://lnkd.in/dtYXSKTe
