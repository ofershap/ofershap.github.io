# 给 Cursor 用户的一个很棒且特别实用的小技巧:

本页为原文的机器翻译，未经人工译者审核。历史信息可能已发生变化。

给 Cursor 用户的一个很棒且特别实用的小技巧:
把你的 AI 代码助手变成真正的伙伴,而不是 "Yes Man"(唯唯诺诺的人)--
如果聊天总是同意你,它并不能真正帮助你成长,只会强化你的盲点,而不是像真正的结对编程(Pair Programming)伙伴那样发挥作用。

🛠️ 在 Cursor 中怎么改进?

我在 User Rules 下加了一条简单的规则:

"Do not blindly agree with my ideas. If you detect a flaw, risk, inefficiency, or a better alternative, challenge my approach respectfully but directly. Prioritize correctness and clarity over politeness or affirmation."

从那以后,Cursor 从一个被动的助手变成了和我一起思考的伙伴。它会提问,指出架构问题,并提出更好的方案 -- 而不只是我要求的内容。

🎯 想在你那边也用上吗?把这段提示词粘贴到设置里:
 Cursor -> Settings -> Cursor settings -> Rules (tab) -> User Rules (text area)

试试看,它会改变整个互动方式。
