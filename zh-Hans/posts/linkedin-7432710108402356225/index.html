现在也有希伯来语版本了:我构建了一个开源工具,可以在视觉上升级 GitHub 个人主页 😎

使用方法:在任意个人主页地址中,把 github.com 替换为 gitshow.dev,例如:
github.com/ofershap → gitshow.dev/ofershap

你会得到 GitHub 没有的功能:

📥 你所有软件包的 npm 下载统计
📦 项目按类别自动分组(MCP Servers、CLI 工具、React 和 UI、DevOps 等)
📊 技术栈、重点领域的可视化,以及项目创建的时间线
🔗 一键分享按钮

GitHub 展示的是一份扁平的仓库列表。GitShow 讲述的是你真正在构建什么的故事。

欢迎试用 -- 只需换成你自己的域名:
gitshow (.) dev / YOUR_USERNAME

对所有人都适用,无论是个人主页还是组织:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)

而且一切都是开源的:
