# 本周,我们为整个研发(R&D)团队完成了一场共 5 节的 Cursor 工作坊,目的是让大家了解 Cursor 这个贯穿整个开发周期的工作工具。

本周,我们为整个研发(R&D)团队完成了一场共 5 节的 Cursor 工作坊,目的是让大家了解 Cursor 这个贯穿整个开发周期的工作工具。

在所有课程中,我们一起走过了流程中的每个阶段 -- 从规划和需求说明,到编写代码和测试,再到代码评审和交付。每一节课上,我们都把 Cursor 与参与者的真实工作联系起来:流程、策略,以及取自该节主题的任务。

重点不只是工具本身,而是实践:如何用它来加速开发、了解它的能力、减少代码错误并改进决策。 
最重要的是,目的是展示它是一个强大、具有变革性、尤其是易于上手的工具,让每位开发者都能开始使用。

是的,还要谈谈它带来的新挑战,以及需要学习的新能力,以便在让它写代码(速度快得难以置信)和继续审视所写代码、告诉它要修复什么以及如何工作(这依然缓慢且具有挑战性,仍然需要开发人员来做)之间找到平衡。 

我们进入了一个新时代:作为掌握全局(上下文)的人,我们已经从手动编写代码,转变为口述代码、规划代码,同时也评审代码。这是一件需要亲身体验、练习、消化并走过的事,才能完成从开发者到 Context Engineer 的转变过程。

归根结底,这样的工作坊与其说是关于 Cursor 能做什么,不如说是关于采用基于 LLM 的开发工具需要什么 -- 作为技术进步和 AI 革命的一部分,而不仅仅是又一个技术附加品。为了保持相关性。

这是一个无法跳过的过程。

感谢所有帮助促成这件事的高手们 💪
