这位以色列人独自打造了一个革命性的工具 -- 没有融资,没有报纸头条,你们应该认识一下他:Eliezer Steinbock

我们都很难应对邮箱里的信息过载 --
Inbox Zero 是一个会扫描并整理你邮箱的系统(当然是用 AI),它会对新闻通讯、营销邮件以及你需要回复的邮件进行分类。它还会为邮件预先准备好回复,过滤垃圾邮件,并对邮件做摘要。

这些不是口号,它确实做得非常出色。而且它已经有超过 8000 名用户可以证明 -- 上线才 3 个月!


同样有意思的是,代码是开源的!也就是说,只要你有技术知识,任何人都可以进去查看代码。这增加了对项目可靠性的信心,也不妨碍客户为其云端托管服务付费订阅。

Eliezer 用 Cursor IDE 这款开发工具构建了整个项目,并在 YouTube 视频和其他渠道中教大家他是怎么做的。

他还创立了 Cursor Israel 社区,并主持相关主题的线下聚会(meetup)。

他分享的重要知识也让他成为 Cursor 在以色列的官方大使!

过去他还创办过其他项目,比如 skilled(以色列的自由职业者市场)和一款梦幻橄榄球游戏。全部是自力更生(bootstrap),没有融资。

他最新的项目 Inbox Zero 被一个名为 TinySeed 的特殊加速器录取,这个加速器只与自力更生的公司合作。

他的项目在 GitHub 上大放异彩,位居基于 TypeScript 的项目榜首,激励着世界各地的开发者。 


独自开发、不融资(bootstrap)的创业者得到的聚光灯和媒体报道较少,这很可惜 -- 因为像 Eliezer 这样的人、他打造的出色工具和他慷慨的分享,对我们来说是一种荣幸,也是以色列的骄傲 🇮🇱
