# 快来看!我在 Cursor 里发现了一个疯狂的 hack 🤓🤘

快来看!我在 Cursor 里发现了一个疯狂的 hack 🤓🤘
你可以给 Cursor 添加一条 User Rule,告诉它你之前的对话保存在哪里,添加如下 Rule:
```
U have access to all conversations of last month - they are stored in: ~/.cursor/projects/[YOUR-WORKSPACE-PATH]/agent-transcripts/
```
(保留 [YOUR-WORKSPACE-PATH] 原样即可,在你打开的任何项目中都有效)

从这一刻起,你可以向它询问过去对话的问题,它会认识并记住它们!
你也可以让它分析这些对话并提取洞察,或做任何其他事情。
想找到消失的对话?你开始了却没完成的话题?一切都敞开。

重要提示:对话会保存 30 天,也就是说只能访问最近 30 天的内容。

如果对你有效请告诉我,欢迎分享你用它做了什么 😎
