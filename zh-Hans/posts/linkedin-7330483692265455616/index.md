# 坐在没有信号的火车上,使用 AI 聊天 🚆

坐在没有信号的火车上,使用 AI 聊天 🚆
我是怎么做到的?

先别管这个:2025 年了,贝特·耶霍舒亚(Beit Yehoshua)到特拉维夫之间的整条线路居然还没有手机信号,真让人难以置信。

所以我暂时找到了一个有创意的办法 -- 使用类似 ChatGPT 的方案,无需联网。

怎么做?
两个简单的步骤:

1. 在 Mac 上安装 Ollama 应用:
 https://ollama.com
 (一键安装,并下载一个免费的模型"包",比如 llama 3.2)

2. 用 Docker 安装 Open Web UI:
 https://www.openwebui.com
只需在终端里运行一条命令

就这样,你在浏览器里就有了一个类似 ChatGPT 的界面,在本地运行。

⚠️ 需要知道的:
- 不支持希伯来语(附有图片,也许有支持的模型,我没有研究)。
- 回答质量不如知名的模型。

但它是私密的、快速的,而且随处可用 -- 即使在没有信号、停驶的火车上。
