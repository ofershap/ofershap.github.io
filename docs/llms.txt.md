# Engagement API documentation

> Machine-readable contract and usage notes for the public engagement API of ofershap.github.io.

- [API documentation](https://ofershap.github.io/docs/): endpoints, rules, examples
- [OpenAPI specification](https://ofershap.github.io/openapi.json): GET /health, GET/POST /stats on https://blog-engagement.ofers.workers.dev
- [API catalog (RFC 9727)](https://ofershap.github.io/.well-known/api-catalog)

## When to use this section

Use it to integrate with the site's real public API: reading article like/view counters or recording a view, like or unlike. Anonymous, no authentication, Origin header required. There is no other public API on this domain.
