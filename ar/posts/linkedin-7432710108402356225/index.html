الآن بالعبرية أيضًا: بنيت أداة مفتوحة المصدر تطوّر بصريًا ملفات GitHub الشخصية 😎

كيف تعمل: استبدلوا github.com بـ gitshow.dev في أي عنوان ملف شخصي، مثلًا:
github.com/ofershap → gitshow.dev/ofershap

وستحصلون على ميزات غير موجودة في GitHub:

📥 إحصائيات تنزيلات npm لجميع حزمكم
📦 مشاريع مجمّعة تلقائيًا بحسب الفئة (خوادم MCP، أدوات CLI، React وواجهات المستخدم، DevOps وغيرها)
📊 تصوّر مرئي للـ stack ومجالات التركيز وخط زمني لإنشاء المشاريع
🔗 أزرار مشاركة بنقرة واحدة

يعرض GitHub قائمة مسطحة من المستودعات. أما GitShow فيروي قصة ما تبنيه فعلًا.

يمكنكم التجربة - فقط استبدلوا باسم نطاقكم:
gitshow (.) dev / YOUR_USERNAME

يعمل مع الجميع، سواء الملفات الشخصية أو المؤسسات:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)
