# بنيت أداة مفتوحة المصدر تمنح ملفات GitHub الشخصية ترقية بصرية.

ترجمة آلية للمنشور الأصلي، لم يراجعها مترجم بشري. قد لا تكون المعلومات التاريخية محدثة.

بنيت أداة مفتوحة المصدر تمنح ملفات GitHub الشخصية ترقية بصرية.

كيف تعمل: استبدلوا "github.com" بـ "gitshow.dev" في أي رابط لملف شخصي.

github.com/ofershap → gitshow.dev/ofershap

ما ستحصلون عليه ولا يعرضه GitHub:

📥 إحصائيات تنزيلات npm لجميع حزمكم
📦 مشاريع مجمّعة تلقائيًا بحسب الفئة (خوادم MCP، أدوات CLI، React وواجهات المستخدم، DevOps...)
📊 تصوّر مرئي للـ tech stack ومجالات التركيز وخط زمني لإنشاء المشاريع
🔗 أزرار مشاركة بنقرة واحدة

يعرض GitHub قائمة مسطحة من المستودعات. أما GitShow فيروي قصة ما تبنيه فعلًا!

جرّبوه الآن - فقط بدّلوا النطاق:
gitshow (.) dev/YOUR_GITHUB_USERNAME

يعمل مع أي شخص، أفرادًا ومؤسسات:
→ gitshow.dev/sindresorhus - 90 projects, 43B npm dl/m (sindresorhus)
→ gitshow.dev/vercel - even works for orgs (vercel)
→ https://lnkd.in/d6Zzftia - 6 repos, 225k stars (torvalds)
→ gitshow.dev/wesbos - 478k npm downloads/month (wesbos)

مفتوح المصدر بالكامل: https://lnkd.in/dtYXSKTe

اكتبوا في التعليقات اسم المستخدم الخاص بكم على GitHub، أريد أن أرى كيف يبدو ملفكم الشخصي ☺️
